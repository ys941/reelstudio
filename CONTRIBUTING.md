# Contributing to ReelStudio

*A full video editor that runs entirely in the browser.*

Thanks for looking. This project was built by one person, after hours, learning
along the way — so there are rough edges, and help with any of them is welcome.

## Ways to help

- **Report a bug.** Tell me what you did, what happened, and what you expected.
  A screenshot or the error text saves a lot of guessing.
- **Suggest a feature.** Open an issue describing the problem you're trying to
  solve, not only the solution you have in mind.
- **Improve the docs.** Fixing one confusing sentence in the README counts.
- **Send a pull request.** First-time contributors are genuinely welcome here.

## Working on the code

```bash
git clone https://github.com/ys941/reelstudio.git
cd reelstudio
```

Then follow the setup steps in the README — it is the single source of truth
for how to run this project locally.

Before opening a pull request:

1. Keep changes focused — one concern per PR is easier to review than five.
2. Match the surrounding style rather than reformatting whole files.
3. Run whatever build, type-check or tests the project has and make sure they pass.
4. Explain *why* in the PR description, not just *what*.
